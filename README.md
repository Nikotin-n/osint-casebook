# OSINT Casebook

A collection of educational case studies and methodologies for open-source intelligence.
Each case describes the objective, approach, tools, and how the result was verified.

## Focus Areas
- Geolocation and image analysis
- Research on domains, companies, and public registries
- Information verification and source reliability assessment
- Digital footprint analysis (on educational targets)
